SOLUS V3 — BRUTALIST / PREMIUM AUTOMOTIVE COLLECTIVE

Open index.html in a browser.

GALLERY:
1) Put as many photos as you like in assets/gallery/ for storage with the project.
2) Because a plain local HTML file cannot automatically list a folder, use “LOAD YOUR GALLERY +” on the page and select the folder containing your photos. Chromium/Chrome/Edge can load a whole folder; the photos are previewed locally in the browser and are not uploaded anywhere.
3) You can also drag/drop a batch of images anywhere onto the page.

The gallery is intentionally large and uses a responsive brutalist mosaic + click-to-lightbox.
The access page is a separate working page with a fake introduction form.
The logo is included as a transparent PNG plus the original JPG.
