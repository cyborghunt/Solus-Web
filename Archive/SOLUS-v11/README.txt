SOLUS — CONCEPT BUILD v6 "LOUD"

FILES
  index.html    Loader → enter screen → homepage
  gallery.html  The Archive (load folder / drag-drop / lightbox)
  access.html   "You don't apply. You get invited."

OPEN
  Double-click index.html. Keep all three files in one folder
  so the links between them work. Photos are embedded inside
  each file — no assets folder to lose.

WHAT TO LOOK FOR
  - Loading counter 000→100 over flickering archive frames
  - SOLUS builds letter by letter, then the screen splits into
    8 vertical slats that lift away
  - Hero: the word SOLUS is cut out of a photo of the whole club
  - Marquee reacts to scroll — faster scroll, faster + skewed
  - Drives run SIDEWAYS as you scroll down (desktop)
  - The Detail: three tight crops with spec captions
  - Custom cursor that inflates and labels itself
    (the native arrow is hidden; it returns on touch)
  - Film grain + scanlines over everything
  - Live telemetry readout in the bottom corners

CONTROLS
  Scroll / Enter / click to pass the intro
  Gallery: LOAD FOLDER + or drag images anywhere onto the page
  Lightbox: arrow keys to move, Esc to close
  Nothing uploads anywhere — added images are session-only

TYPEFACES
  Anton + Inter + IBM Plex Mono via Google Fonts.
  Needs a connection to look exactly right; offline it falls
  back to Impact / Arial Narrow and still holds together.

MOBILE
  Sideways drives stack vertically, cursor and telemetry
  switch off, grain stays.

LOGO
