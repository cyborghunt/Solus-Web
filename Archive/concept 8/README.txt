SOLUS — CONCEPT BUILD (brutalist / v6)

FILES
  index.html    Homepage. Scroll-to-enter intro, hero, collective,
                drives ledger, gallery tease, inverted detail band, access.
  gallery.html  The Archive. Load-folder / drag-drop / lightbox.
  access.html   "You don't apply. You get invited." + introduction request.

HOW TO OPEN
  Double-click index.html. That's it.
  All photography is embedded inside each file, so there is no
  assets folder to lose and nothing breaks when you move or send them.
  Keep the three files in the same folder so the links between
  pages keep working.

GALLERY
  LOAD FOLDER +  pick a whole folder of photos
  or drag a batch of images anywhere onto the page
  Click any frame to open the lightbox (arrow keys / Esc work)
  Nothing uploads anywhere. Added images live in that browser
  session only — refreshing clears them.

TYPEFACES
  Anton (display) + Inter (body) + IBM Plex Mono (data),
  loaded from Google Fonts. Online it looks as intended;
  offline it falls back to Impact / Arial Narrow and still holds.
